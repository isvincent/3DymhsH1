# 🌸 梅岡歲月 3D 數位校史館 (1948 - 2018)

**桃園市立楊梅高級中等學校（National / Taoyuan Municipal Yangmei Senior High School）** 互動式 3D 校史博物館。  
本專案整合 **60 週年校慶專刊《菁莪慶花甲 梅岡展風華》** 與 **70 週年校慶專刊《梅高七十 迎曦御風》** 兩份珍貴史料，透過 WebGL (Three.js) 將 1948 年至 2018 年橫跨 70 載的創校沿革、建築演進、校園傳奇記憶與師生榮耀化為可自由穿梭的 3D 星際時光隧道。

---

## ✨ 核心特色

1. **雙史料完整融合（1948–2018）**
   - **創校與改制**：1948 縣立楊梅初中創校（首任校長張芳杰）→ 1951 縣立楊梅中學 → 1968 省立楊梅高中籌備（5月17日校慶日）→ 1969 正式創校（史振鼎校長）→ 2000 改制國立楊梅高中 → 2018 改隸桃園市立楊梅高級中等學校。
   - **校園建設演進**：梅岡新村、梅岡精神堡壘、鏡池、400米跑道、啟明樓（圖書館）、鼎園、四大樓命名（御風樓、迎曦樓、悅知樓、蘊慧樓）、紅土藝術空間、日新樓、公共藝術「梅岡鹿鳴」及 2018 校史室啟用。
   - **梅岡獨家記憶（60週年史料精選）**：好漢坡（健身坡）、月眉橋、夢湖、五絕山五絕景（鏡湖邀霞、飛鶴點水、小樓迎風、西廂待月、斷崖醒魂）、校歌與第二校歌《梅岡寄情》（金弦獎）、山上和尚院與山下修女院、擠校車爬好漢坡、第一屆工科收音機實習、香山堂行軍記、軍歌比賽與越野賽跑。
   - **卓越榮耀紀錄**：桃聯榜首周蓮香教授、巧固球與射箭全國稱霸、教育部「教學卓越獎」（《人與地的對話》、《埤塘新樂園》）、全國工科技藝競賽「金手獎」群英、全國科展、美術與管樂佳績。

2. **沉浸式 3D 互動體驗 (Three.js + GSAP)**
   - 以四種不同 3D 發光幾何體代表四大主題（八面晶體：創校改制、建築方塊：校園建設、流線結：梅岡記憶、二十面寶石：卓越榮耀）。
   - 支援點擊 3D 節點飛行、時間軸滑桿拖曳、分類過濾、關鍵字全文檢索以及「自動導覽」播放模式。

3. **RWD 響應式網頁設計 & PWA 支援**
   - **跨裝置相容**：桌機支援滑鼠滾輪、方向鍵與 3D 點選；平板與手機支援上下滑動漫遊與底部自適應玻璃擬態資訊卡。
   - **PWA 離線能力**：內建 `manifest.json` 與 `sw.js` Service Worker，可安裝至電腦桌面或手機主畫面，並支援離線開啟。

```text

└── README.md           # 專案說明文件
```

## 🚀 部署至 GitHub Pages 步驟

1. 在 GitHub 建立一個新的公開儲存庫（Repository），例如 `ymhs-history-3d`。
2. 將本專案解壓縮後的 5 個檔案（`index.html`、`manifest.json`、`sw.js`、`icon.svg`、`README.md`）上傳至儲存庫根目錄。
3. 進入儲存庫的 **Settings** > **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`（或 `master`）及 `/ (root)`，點擊 **Save**。
5. 等待約 1～2 分鐘後，即可透過 `https://<您的GitHub帳號>.github.io/ymhs-history-3d/` 瀏覽並安裝 PWA 應用程式。
